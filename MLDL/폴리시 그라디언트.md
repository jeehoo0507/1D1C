## Policy Gradient 정리

### 1. 정책 ( \pi_\theta )

입력 (x)가 들어오면 정책 신경망이 **출력들의 확률분포**를 만든다.

[  
\pi_\theta(\cdot|x)  
]

예:

# [  
\pi_\theta(\cdot|x)

[0.1,\ 0.7,\ 0.2]  
]

여기서 실제 출력 (y=B)가 샘플링되었다면

[  
\pi_\theta(B|x)=0.7  
]

이다.

---

### 2. 출력에 보상을 준다

생성한 출력 (y)를 평가해서

[  
R(y)  
]

라는 **스칼라 보상**을 만든다.

예:

[  
R(y)=0.9  
]

---

### 3. 우리가 원하는 목표

좋은 출력을 많이 생성하도록 정책을 바꾸고 싶다.

그래서

# [  
\boxed{  
J(\theta)

\mathbb E_{y\sim\pi_\theta}[R(y)]  
}  
]

를 **최대화**한다.

즉,

> 정책에서 출력을 뽑았을 때 평균적으로 받는 보상을 최대화한다.

---

### 4. 그런데 기대값을 직접 계산하기 어렵다

가능한 출력이 너무 많기 때문에

[  
\sum_y \pi_\theta(y|x)R(y)  
]

를 전부 계산할 수 없다.

그래서 정책에서 실제로 여러 번 샘플링한다.

[  
y_1,y_2,\ldots,y_N  
\sim\pi_\theta  
]

그리고 샘플들의 보상 평균으로 기대값을 근사한다.

[  
\mathbb E[R]  
\approx  
\frac1N\sum_{i=1}^N R(y_i)  
]

---

### 5. 기대값을 미분하면 Policy Gradient가 나온다

목표가

[  
J(\theta)=\mathbb E[R(y)]  
]

이므로

[  
\nabla_\theta J(\theta)  
]

를 구한다.

수학적으로 정리하면

# [  
\boxed{  
\nabla_\theta J(\theta)

\mathbb E  
\left[  
R(y)  
\nabla_\theta\log\pi_\theta(y|x)  
\right]  
}  
]

이게 **Policy Gradient**의 핵심 공식이다.

---

### 6. 이 식을 직관적으로 보면

[  
\boxed{  
R(y)  
\nabla_\theta\log\pi_\theta(y|x)  
}  
]

에서

[  
\nabla_\theta\log\pi_\theta(y|x)  
]

는

> **현재 출력 (y)의 확률을 어느 방향으로 바꾸면 되는가**

를 나타내고,

[  
R(y)  
]

는

> **그 방향으로 얼마나 강하게 바꿀 것인가**

를 결정한다.

따라서

- 높은 보상 → 그 출력의 확률을 **높이는 방향**
    
- 낮은 보상 → 그 출력의 확률을 **낮추는 방향**
    

으로 학습된다.

---

### 7. 경사하강법을 쓰려면 부호를 바꾼다

우리는 원래

[  
\max_\theta J(\theta)  
]

를 하고 싶다.

하지만 optimizer는 일반적으로 loss를 최소화한다.

따라서

[  
\boxed{  
L=-R(y)\log\pi_\theta(y|x)  
}  
]

라는 loss를 사용한다.

그리고

[  
\boxed{  
\theta  
\leftarrow  
\theta-\eta\nabla_\theta L  
}  
]

로 업데이트한다.

---

### 8. LLM에서는 문장 전체를 어떻게 처리하나

문장

[  
y=(y_1,y_2,\ldots,y_T)  
]

를 생성했다면 문장 전체 확률은

# [  
\pi_\theta(y|x)

\prod_{t=1}^{T}  
\pi_\theta(y_t|x,y_{<t})  
]

이다.

따라서

# [  
\log\pi_\theta(y|x)

\sum_{t=1}^{T}  
\log\pi_\theta(y_t|x,y_{<t})  
]

이고 loss는

[  
\boxed{  
L=  
-R(y)  
\sum_{t=1}^{T}  
\log\pi_\theta(y_t|x,y_{<t})  
}  
]

가 된다.

즉 **문장 전체에서 받은 하나의 보상 (R)이 그 문장을 구성한 각 토큰의 log probability에 연결된다.**

---

## 전체 흐름

[  
\boxed{  
x  
\rightarrow  
\pi_\theta(\cdot|x)  
\rightarrow  
y\text{ 샘플링}  
\rightarrow  
R(y)  
\rightarrow  
\log\pi_\theta(y|x)  
\rightarrow  
L=-R\log\pi  
\rightarrow  
\text{역전파}  
\rightarrow  
\nabla_\theta L  
\rightarrow  
\theta\text{ 업데이트}  
}  
]

가장 중요한 한 줄만 기억하면:

# [  
\boxed{  
\text{Policy Gradient}

\text{보상}  
\times  
\text{출력 확률의 로그에 대한 gradient}  
}  
]

그리고 **보상 (R) 자체를 미분하는 게 아니다.**  
보상은 "이 출력이 얼마나 좋았는지"를 나타내는 숫자로 사용하고, 실제 미분은

[  
\log\pi_\theta(y|x)  
]

를 통해 신경망의 가중치까지 역전파한다.


여기서 E 기댓값을 보상들의 평균으로 근사가능한것은 
실제로는 보상 곱하기 출력 확률이지만 
많이 시도하면 보상이 출력 확률만큼 등장 할 것이기 때문이다.
