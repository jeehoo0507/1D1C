지금까지 나온 단순, 다중 선형 회귀 분석에는 큰 문제가 있다
바로 과적합 문제이다.
이를 해결하기 위해서 특정 가중치가 너무 커지거나 너무 작아지는 것을 제약 해 줄 필요가 있다.
==과적합== : 학습 데이터에 과도하게 맞춰져서 새로운 데이터에 대한 예측을 잘 못하는 현상

이를 해결하기 위해 이번 릿지(Ridge) 라쏘(Lasso) 회귀에서는 기존 $loss$ 에 가중치 크기를 더해준다.
$$loss = MSE + weigt\ size$$

### $Ridge$(L2 정규화)
---

$$cost(W, b) = MSE + \lambda \sum W_j^2 $$


수식은 기존 선형 회귀의 $loss$ 에 각 가중치의 제곱을 더한 꼴을 가진다.
릿지 회귀에서 가중치들 중 의미없는 가중치들은 0에 가까워진다. (0이 되진 않음)

이는 간단하게 $loss$를 미분해보면 알 수 있다.

$$cost(W, b) = \frac{1}{n} \sum (y^{(i)} \ -\ H(x^{(i)}))^2 + \lambda W_j^2$$

가중치 제약 부분에 대한 미분
$$\frac{\partial}{\partial W_j} (\lambda W_j^2)= 2\lambda W_j$$
기존 $MSE \ loss$ 부분 미분을 $G_j$ 라 하면

$$\frac {\partial cost}{\partial W_j} = G_j + 2\lambda W_j$$

최종 기울기 업데이트 수식은
$$W_j := W_j \times (1-2\alpha \lambda) - \alpha G_j$$
$\alpha$ : 학습률  $\lambda$ : 정규화 파라미터

여기서 $\lambda$는 양수이고 $\alpha$ 는 1보다 작은 수 이므로
매 반복(step)마다 $W_j$를 약간 줄이고 시작함을 알 수 있다.
이를 가중치 감쇠(weight decay)라고 한다. 가중치 업데이트 시 일정 비율(%)로 줄어들기에 작은 건 작게 큰 건 크게 줄어들기에 0에 가까워지는 것이지 0이 되는 것은 아니다.


### $Lasso$(L1 정규화)
---
$$cost(W, b) = MSE + \lambda \sum \vert W_j \vert $$

라쏘 회귀는 의미 없는 가중치는 아예 0이 되어버린다.

이 또한 가중치 제약 부분에 대해 미분 
$$\frac{\partial}{\partial W_j} (\lambda \vert W_j \vert)= \lambda \cdot sign(W_j)$$
$$sign(x) = \begin{cases} +1 & x > 0 \\ 0 & x = 0 \\ -1 & x < 0 \end{cases}$$



위 식을 통해 양의 가중치 값은 줄이고, 음의 가중치 값은 키운다는 것을 확인 할 수 있다.
이는 초기부터 작은 가중치 값은 0 일정 크기 만큼 줄어들기에 0에 근접해지는 것을 의미한다.
(릿지 회귀에서는 미분 후 $W$가 남아 가중치 크기에 비례했지만 라쏘 회귀는 가중치 크기에 영향을 받지 않는다.)
