### 수학적 이해
---
다중 선형 회귀 분석은 단순 성형 회귀 분석에서
입력 변수(독립 변수) $x$가 여러 개인 것을 말한다.

예를 들어 입력 값이 3개 라면 아래와 같이 표현 가능하다.
$$H(x_1, x_2, x_3) = w_1x_1 + w_2x_2 + w_3x_3$$

#### 선형 회귀 분석
---
단순 선형 회귀 분석으로 돌아가본다면 
$$cost(W, b) = \frac{1}{n} \sum_{i=1}^{n} \left[ y^{(i)} - H(x^{(i)}) \right]^2$$
```python
cost = torch.mean((hypothesis - y_train) ** 2)
```
cost 함수의 정의가 다음과 같이 시그마가 빠져있는 것을 확인 가능하다.

이는 optim.step() 이 한 번 실행될 때 전체 데이터를 모두 계산 한다는 것을 의미한다.

#### 다중 선형 회귀 분석
---
이론적으로는 선형 회귀 분석과 같기 때문에 경사하강법의 차이점만 알아두고 가자

$$ H(x) = w_1x_1+w_2x_2+w_3x_3$$

| $w_1$    | $w_2$    | $w_3$    | $y$   |
| -------- | -------- | -------- | ----- |
| $x_{11}$ | $x_{12}$ | $x_{13}$ | $y_1$ |
| $x_{21}$ | $x_{22}$ | $x_{23}$ | $y_2$ |
| $x_{31}$ | $x_{32}$ | $x_{33}$ | $y_3$ |
예를 들어 $w_1$에 대해 업데이트 하고 싶다면 $\frac {\partial cost}{\partial w_1}$을 계산해야한다.
이는  $(H - y)^2$ 에 $w_1$ 계수에 붙었던 입력값들이 추가로 곱해지는 꼴을 하게 된다.

$$\frac{\partial cost}{\partial W_j} = -\frac{2}{n}\sum_{i=1}^{n} x_j^{(i)}\left(y^{(i)} - H(x^{(i)})\right) \quad (i : row, j:cloumn)$$
