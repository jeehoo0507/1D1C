### 수학적 이해
---
로지스틱 회귀는 분류, 그중에서도 클래스(class)가 2개인 ==이진 분류==(Binary Classification)에서 많이 사용된다.
뒤에서 나오겠지만 분류 문제에서 주로 사용됨에도 회귀라는 이름을 가진 이유는 모델이 예측하는 값 자체는 0~1사이의 연속적인 값이기 때문이다. 

### 식 유도
---
####  풀고 싶은 문제
```latex
이메일 하나를 보고 "스팸인가?"를 맞히고 싶다.
```

가진 특성들을 보면 링크 개수 $x_1$, 느낌표 개수 $x_2$, 발신자 평판 점수 $x_3$  ...

가장 처음 생각해 볼 수 있는 것은 선형 결합입니다.
$$z = \beta_0 + \beta_1 \ x_1 + \beta_2 \ x_2+\beta_3 \ x_3+ \cdots$$
이게 왜 쉬운가? 선형 회귀 분석에서도 봤듯이 미분이 쉽고, 해석이 쉽습니다


#### 문제점
하지만 우리가 하고 싶은 건 스팸일 ==확률== 입니다.
"이 메일은 82% 확률로 스팸이야!"와 같이 되야 하는 것입니다.

지금 우리가 만든 선형식 $z = \beta ^T x$ 는 $-\infty$ 부터 $\infty$ 까지 나옵니다.

$$p \in (0,1) \quad vs \quad \beta^T x \in (-\infty,\infty) $$
여기서 선택지는 두 가지입니다.

(A) 선형식을 (0, 1) 안에 구겨넣는다
(B) 확률을  $(-\infty,\infty)$로 늘려서 선형식과 같게 한다.

이번 로지스틱 회귀는 (B)를 택합니다.
이는 두 단계롤 이루어집니다.



#### 늘리기 1 - 오즈
오즈(odds)는 확률을 비(比)로 표현하는 방식입니다.

$$odds = \frac{p}{1-p} = \frac{\text{일어날 확률}}{\text{안 일어날 확률}}$$
$p =0.5$ -> $odds = 1$ (반반)
$p = 0.9$ -> $odds = 9$
$p = 0.99$ -> $odds = 99$
$p$가 1에 가까워 질수록 무한대로 간다. 이를 통해 범위가 $(0,\infty)$ 가 되었다.



련셋으로 골라도 되나?" 하는 여지가 남거든요. 근데 이건 필수 조건이라 명시하는 게 좋아요.

#### 늘리기 2 - 로그
이제 남은 $-\infty$를 해결해야 합니다 오즈는 음수가 안되기 때문입니다.
이를 해결해주는 것이 바로 로그입니다.
$$log(\text{작은 양수}) -> -\infty, \quad log(\text{큰 양수})-> +\infty$$
그래서
$$logit(p) = log \frac{p}{1-p}$$
이걸 로그 오즈 또는 로짓(logit) 이라 합니다.



#### 전개
$$log \frac{p}{1-p} = \beta_0 + \beta_1 \ x_1 + \beta_2 \ x_2+\beta_3 \ x_3+ \cdots$$
이제 양쪽에 표현 가능한 범위가 같아졌으니 등호로 연결 가능합니다.

전개 해보면
$$log \frac{p}{1-p} = z$$
$$\frac {p}{1-p} = e^z$$
$$p = e^z(1-p)$$
$$p = \frac{e^z}{1+e^z} = \frac{1}{1+e^{-z}} = \sigma (z)$$

### 분류
시그모이드 함수는 입력값에 대해 확률 0~1 사이를 출력하는데 여기서 0.5를 기준으로 분류하면 됩니다.
A, B 두 클래스가 있을 때 0.5 보다 낮으면 A, 0.5 보다 높으면 B 
- 0.5이면 어떻게?? 
어차피 0.5라는 값도 관습적인거라 그냥 원하는 데로 하거나 아래 예시처럼 특정 케이스에서 유동적으로 정하면 됨

1. 암 진단 : 맞는 걸 아니라고 할 수 있으니(FN) 임계값을 0.2정도로 낮춤
2. 스팸 필터 : 중요한 이메일이 스팸함 가면 안됨 -> 임계값을 0.2정도로

임계값 (0.1, 0.2, 0.3, ...) 등등 특정 임계값을 미리 정하고 검증 데이터 셋에서 각 임계값 중  성능이 좋은 걸(F1같은 지표들) 채택하는 즉, 실험적으로 임계값을 정하는 방법도 사용된다.


### 손실
---
#### 쉬움
---
![[Pasted image 20260803234554.png]]
간단하게 생각해보면 실제값이 1일 때 예측값이 0에 가깝다면 오차가 커야하고 마찬가지로 실제값이 0일 때 예측값이 1에 가까워지면 오차가 커야합니다.
그리고 이를 충족하는 함수와 위에 보이는 로스 함수를 교차시킨 ==BCE(binary cross-entropy)== 로스 함수입니다. (log-loss로도 불림)

$$if\ \  y = 1 \rightarrow cost(H(x), \ y) = -log ((H))$$
$$if\ \  y = 0 \rightarrow cost(H(x), \ y) = -log (1-(H))$$
##### 최종 함수
$$\text{cost}(H(x), y) = -\left[y \log H(x) + (1-y) \log(1 - H(x))\right]$$


#### 심화
---
$$p = P(y=1 \mid x)$$
우리는 $p$를 $y=1$ 일 확률로 정의했습니다.

$y=0$일 확률은 자연스럽게 $1-p$ 입니다.
$$P(y=0 \mid x) = 1-p$$
그럼 이런 기준을 생각해볼 수 있습니다.
```latex
"정답이 1일 때 p 가 1에 가까우면 높은 점수, 정답이 0일 때 p 가 0에 가까우면 높은 점수를 주는 함수를 만들고, 이것을 최대화하면 되겠구나!"
```
그런데 이 조건을 만족하는 함수를 새로 설계할 필요가 없습니다.
이미 모델이 계산해놓은 확률 자체가 그 조건을 만족하기 때문입니다.

$$
P(y \mid x) = \begin{cases}
p & y = 1 \\
1-p & y = 0
\end{cases}
$$

하지만 이 경우 미분이 불가한 함수이 때문에
$$P(y \mid x) = p^{y}(1-p)^{1-y}$$

간단한 트릭으로 지수가 스위치 역할을 하게 해서 위에서 의도하였던 내용을 담을 수 있습니다.


$$
L = \prod_{i=1}^{m}p_i^{y_i}(1-p_i)^{1-y_i}
$$
이것을 우도(likelihood)하고 합니다
여기서 곱하는 이유는 어떤 사건이 관측 될 확률로 생각하기 때문입니다.
(확신을 가지고 틀리면 값이 확 작아짐)


$$log L = ylog p+(1-y)log(1-p)$$

굳이 $log$를 취하는 이유는 크게 3가지가 있습니다.

##### 1. 값이 너무 작다
대부분 $0.a^n$ 꼴이 등장할텐데 값이 너무 작아지면 컴퓨터가 처리하기 힘듭니다.

##### 2. 미분 어려움
곱의 미분은 항의 개수 만큼 덩어리가 생기기 떄문에 계산이 불가합니다.(계산량이 많음)
$$
(fgh)' = f'gh + fg'h + fgh'
$$
##### 3. 지수 형태
$p^y$처럼 지수에 변수가 있는 형태도 미분이 힘듭니다.
$$
log(ab) = log\ a+log \ b \quad log\ (a)^b = b\ log \ a
$$

또한 $log$는 단조 증가 함수이므로 타당합니다($L$이 클수로 $log\ L$ 도 큼)
$$a>b  \implies log\ a> log\ b$$

#### 최종
---
우리는 우도를 크게 만드는 걸 목적으로 설정했습니다.  
$L$ 을 최대화하는 방식으로 파라미터를 추정하는 것을 ==MLE(최대우도추정법)==이라 합니다.  
최대화가 목적이므로 기울기의 반대 방향이 아닌 기울기 방향으로 업데이트해야 합니다.

$$\beta \leftarrow \beta + \lambda \nabla_\beta \ell(\beta)$$
$\ell$은 로그 우도

### 경사상승법
---
$\beta_j$ 가 $\ell$ 까지 가는 방법은 아래와 같습니다.

$$\beta_j \;\to\; z = \beta^\top x \;\to\; p = \sigma(z) \;\to\; \ell$$

연쇄 법칙(체인룰)을 이용하면 아래와 같이 쪼갤 수 있습니다.

$$\frac{\partial \ell}{\partial \beta_j} = \frac{\partial \ell}{\partial p}\cdot\frac{\partial p}{\partial z}\cdot\frac{\partial z}{\partial \beta_j}$$

#### 1. $\partial\ell/\partial p$
$$(\log u)' = u'/u$$ 

$$\frac{\partial \ell}{\partial p} = \frac{y}{p} + (1-y)\cdot\frac{-1}{1-p} = \frac{y}{p} - \frac{1-y}{1-p}$$

$$= \frac{y(1-p) - (1-y)p}{p(1-p)} = \frac{y - yp - p + yp}{p(1-p)} = \frac{y-p}{p(1-p)}$$

$$\boxed{\frac{\partial \ell}{\partial p} = \frac{y-p}{p(1-p)}}$$

#### 2. $\partial p/\partial z$

$$\sigma(z) = \frac{1}{1+e^{-z}} = (1+e^{-z})^{-1}$$

$$\sigma'(z) = -(1+e^{-z})^{-2}\cdot(-e^{-z}) = \frac{e^{-z}}{(1+e^{-z})^{2}}$$

$$= \frac{1}{1+e^{-z}}\cdot\frac{e^{-z}}{1+e^{-z}}$$

$$\frac{e^{-z}}{1+e^{-z}} = \frac{(1+e^{-z}) - 1}{1+e^{-z}} = 1 - \frac{1}{1+e^{-z}} = 1-p$$

$$\boxed{\frac{\partial p}{\partial z} = p(1-p)}$$

#### 3. $\partial z/\partial \beta_j$

$$z = \beta_0 + \beta_1x_1 + \cdots + \beta_jx_j + \cdots$$

$$\boxed{\frac{\partial z}{\partial \beta_j} = x_j}$$



#### 4. 합치기
$$\frac{\partial \ell}{\partial \beta_j} = {\frac{y-p}{p(1-p)}}\cdot{p(1-p)}\cdot{x_j}$$
$$\frac{\partial \ell}{\partial \beta_j} = (y-p)\,x_j$$
$$\frac{\partial \ell}{\partial \beta_j} = \sum_{i=1}^{m}(y_i - p_i)\,x_{ij}$$

$$\beta \;\leftarrow\; \beta + \lambda\sum_{i=1}^{m}(y_i - p_i)\,x_i$$

결국 이 식은 $\beta$ 변화에 대한 $loss$ 값 변화가 최대가 되는 지점을 찾는 것이므로 $\lambda$를 곱해서 더하기만 하면 된다.


### 데이터 의존 줄이기
---
여기서 문제점이 하나 있는데 데이터의 오차가 데이터셋의 크기에 영향을 받는다는 점입니다.

평균적으로 오차가 0.3이라 하면 데이터 개수가 100개 일때에는 30, 1만개 일때는 3000 만큼 오차가 발생합니다. 이를 해결하기 위해서는 데이터셋의 크기 만큼 나눠주어야합니다.

$$\beta \;\leftarrow\; \beta + \lambda\frac{1}{m}\sum_{i=1}^{m}(y_i - p_i)\,x_i$$

$$\lambda : = \frac{\lambda}{m}$$
```python
lr = 0.01 / m
```

하지만 이런식으로 하면 lr를 정할 때 m으로 나눠줘야 한다는 점이 있으므로 그냥 식에 포함시킵니다.

그래서 $\ell$ 대신 $J$로 많이 표기함
$$J(\beta) = -\frac{1}{m}\sum_{i=1}^{m}\big[y_i\log p_i + (1-y_i)\log(1-p_i)\big]$$
$$\frac{\partial J}{\partial \beta_j} = -\frac{1}{m}\sum_{i=1}^{m}(y_i - p_i)\,x_{ij}$$
$$\beta \;\leftarrow\; \beta - \lambda \frac{\partial J}{\partial \beta_j}$$
이런 식으로 하면 경사하강법과 식이 같아짐
