## 소개
---
텐서(Tensor)는 머신러닝의 근본적인 구성 요소입니다.
텐서는 벡터(1차원 배열)와 행렬(2차원 배열)을 포함하는 다차원 숫자 배열(N-dimensional array)을 의미합니다.

@ rank 
선형대수학의 독립인 행/열의 개수를 rank라 합니다. 
그러나 인공지능 분야에서 텐서의 rank는 축의 개수를 의미합니다.

ex) `(A, B, C)` 면 rank3


텐서가 하는 일은 데이터를 수치로 표현하는 것입니다.
예를 들어 이미지를 shape이 `[3, 224, 224]` 인 텐서로 표현할 수 있습니다.
이는 `[컬러_채널, 높이, 너비]` 을 뜻하며 이미지가 3개의 컬러 채널(빨, 파, 초)을 가지고
높이 224 픽셀, 너비 224 픽셀이라는 뜻입니다.

텐서 용어로 말하면 이 텐서는 `컬러_채널`, `높이`, `너비` 각각에 해당하는 세 개의 차원을 가집니다.


## 텐서 만들기
---
Pytorch는 텐서를 정말 좋아합니다. 무려 `torch.Tensor` 클래스만을 위한 문서 페이지가 따로 있을 정도입니다. [torch.Tensor 문서](https://docs.pytorch.org/docs/2.13/tensors.html)

- 스칼라 만들기
스칼라는 하나의 숫자이며 텐서 용어로는 0차원 텐서입니다.

```python
scalar = torch.Tensor(7)
scalar
```

```bash
tensor(7)
```

위에서 tensor(7)이 출력된 이유는 
scalar는 숫자 하나이긴 하지만 타입이 torch.Tensor 라는 뜻입니다.
ndim 속성으로 텐서의 차원 수를 확인할 수 있습니다.



![[Pasted image 20260814013520.png]]

이런 3 x 224 x 224 텐서의 shape는 [3, 224, 244]가 되고 이것의 ndim은 3이 됩니다.
