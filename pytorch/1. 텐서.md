## 소개
---
텐서(Tensor)는 머신러닝의 근본적인 구성 요소입니다.
텐서는 벡터(1차원 배열)와 행렬(2차원 배열)을 포함하는 다차원 숫자 배열(N-dimensional array)을 의미합니다.

@ rank 
선형대수학의 독립인 행/열의 개수를 rank라 합니다. 
그러나 인공지능 분야에서 텐서의 rank는 축의 개수를 의미합니다.

ex) `(A, B, C)` 면 rank 3


텐서가 하는 일은 데이터를 수치로 표현하는 것입니다.
예를 들어 이미지를 shape이 `[3, 224, 224]` 인 텐서로 표현할 수 있습니다.
이는 `[컬러_채널, 높이, 너비]` 을 뜻하며 이미지가 3개의 컬러 채널(빨, 파, 초)을 가지고
높이 224 픽셀, 너비 224 픽셀이라는 뜻입니다.

텐서 용어로 말하면 이 텐서는 `컬러_채널`, `높이`, `너비` 각각에 해당하는 세 개의 차원을 가집니다.


## 텐서 만들기
---
Pytorch는 텐서를 정말 좋아합니다. 무려 `torch.Tensor` 클래스만을 위한 문서 페이지가 따로 있을 정도입니다. [torch.Tensor 문서](https://docs.pytorch.org/docs/2.13/tensors.html)

- 스칼라 만들기
스칼라는 하나의 숫자이며 텐서 용어로는 0차원 텐서입니다.

```python
scalar = torch.Tensor(7)
scalar
```

```bash
tensor(7)
```

위에서 tensor(7)이 출력된 이유는 
scalar는 숫자 하나이긴 하지만 타입이 torch.Tensor 라는 뜻입니다.
ndim 속성으로 텐서의 차원 수를 확인할 수 있습니다.

```python
scalar.ndim
```

```bash
0
```

텐서에서 숫자만 꺼내고 싶다면 어떻게 할까요?
이는 `item()` 메서드를 사용하면 됩니다.

~~~python
scalar.item()
~~~

```bash
7
```


- 벡터 만들기
벡터는 1차원 텐서지만 여러 숫자를 담을 수 있습니다.
~~~python
vector = torch.Tensor([7,7])
vector
~~~

```bash
tensor([7,7])
```

```python
vector.ndim
```

vector에는 숫자가 두 개인데 차원은 하나뿐입니다.
Pytorch에서 차원 수는 대괄호(`[`) 의 개수로 알 수 있습니다, 한쪽만 세면 됩니다.

~~~python
vector.shape
~~~

```bash
torch.Size([2])
```

- 행렬 만들기
~~~python
MATRIX = torch.tensor([[7, 8], 
                       [9, 10]])
MATRIX
~~~

```bash
tensor([[ 7,  8],
        [ 9, 10]])t
```


```python
MATRIX.ndim
```

```bash
2
```

```python
MATRIX.shape
```

```bash
torch.Size([2, 2])
```


![[Pasted image 20260816221754.png]]

이제는 전체적인 요령에 대해 알아봅시다.
우선 tensor의 차원은 대괄호 세기로 쉽게 구할 수 있습니다.
그렇다면 shape는 어떨까요?
shape는 대괄호 안에 묶음을 확인하면 됩니다. 즉 대괄호 하나가 인덱스(정확히는 축)을 담당하는 것이죠.

예시를 통해 보자면 위 사진에 첫 대괄호 안에는 1개의 대괄호 묶음이 있습니다.
그래서 0번째 인덱스에는 1이 들어갑니다.
두 번째 대괄호 안에는 총 3개의 대괄호 묶음이 들어갑니다. 그래서 1번 인덱스에는 3이 들어갑니다.
마지막으로 세번째 대괄호 안에는 3개의 숫자가 있습니다. 그래서 2번 인덱스에는 3이 들어가죠.
마치 행렬을 처음 배울 떄 처럼 묶음이 여러개 이면 모든 묶음 안 묶음 개수는 같기 때문에 하나의 묶음 안 묶음의 개수만 세면 되는 것입니다!!!
