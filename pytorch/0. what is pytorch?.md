[Pytorch](https://pytorch.org/)는 오픈 소스 머신러닝&딥러닝 프레임 워크입니다.

### 무엇을 할 수 있는가?
Pytorch를 쓰면 Python 코드로 데이터를 다루고 처리하며 머신러닝 알고리즘을 작성 할 수 있습니다.

### 누가 pytorch를 사용하나요?
Meta, Tesla, Microsoft 같은 세계 최대 기술 기업들과 OpenAI 같은 인공지능 연구 기업들이 연구를 진행하거나 머신러닝을 제품에 적용하기 위해 Pytorch를 사용합니다.

### 왜 Pytorch를 사용하는가?
Pytorch는 GPU 가속과 같은 여러 작업들을 내부에서 알아서 처리해 줍니다.
