만들게 된 이유
슈딩이 놀이터에서의 슈딩이 행동 센서의 객체 인식 모델의 한계점을 개선하고 
추후 슈딩이 컬렉터의 기반이 되는 메인 파이프라인을 구성하기 위해 이를 만들게 되었다.

1. 슈딩이의 행동이 어떤 행동인지 판단 가능함
2. 특정 행동을 하는 슈딩이 사진을 모아볼 수 있음
   (기존 여러 갈래로 나눠져 있는 슈딩이 사진들을 탐색이나 비교적 고성능의 모델 없이 가능하다.)

main 설계
이번에 사용한 CLIP의 파이프라인은 코사인 유사도 기반 로스를 가지기 떄문에 로스 전파가 적은 데이터 일수록 큰 효과를 보지 못할 가능성이 높다.
그래서 이번 설계에서는 pose 모델을 사용하지 않은 현재 시점 모델에서 최적의 프롬프트를 실험을 통해 검출하고 이를 자동 라우팅 하는 방식으로 확장한다.
또한 추후 최적의 환경에서의 사진이 아닌 noisy한 상황에서의 사진에서 yolo를 통한 바운딩 박스 정보를 입력값에 추가함에 따라 기존 대비 성능 증가 그리고 객체 인식 후 입력과의 비교를 진행한다.
또한 논문에서 제시 된 GPT2 인코더는 오래 된 모델이라는 점에서 감안하여 BERT 모델로 성능을 올린다.

이 모델은 통해 추후 개설하게 될 슈딩이 사진 검색 사이트에 초기 시연 모델로 사용 될 예정이며,
현재로써는 CLIP의 국소적 자세 추정 약점으로 인하여 text to image 형식의 엄청난 편의성을 제공해주지 않지만 여기서 더 나아가서 openpose, vitpose 등과 같은 pose 관절 추정 모델을 결합한 하이브리드 모델 S'LIP 2를 기대한다.

1. 기본 CLIP 코드 짜기
2. 사전 학습 된 CLIP에 아무 고양이 자세 데이터로 학습
3. 슈딩이 사진으로 전처리한 텍스트로 추가 학습
4. 인코더는 BERT 모델 사용 && yolo를 이용한 바인딩 박스 정보를 추가
