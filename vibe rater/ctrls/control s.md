# 소개
---
이 프로젝트는 서버컴을 제어하고 (control s) 자신의 폴더를 저장하는 (ctrl s) 편의성을 제공하기 위한 프로젝트 입니다.


### 문제점
1. 저장 공간의 부족
2. 누가 무슨 작업하는 중인지 알 수 없음
3. CPU, GPU 제한을 좀 더 쉽게 다룰 수 있으면 좋겠음

### 기능
- [x] 현재 누가 무슨 작업 중인지 알 수 있게 하기
- [x] GPU, CPU 제한 한 줄 실행으로 처리하기
- [ ] git push 후 폴더 아카이빙을 통해 저장 공간 관리하기
- [x] toml 파일 생성

☑
언어 : 파이썬
이유 : uv 환경에서 좀 더 편하게 동작시키기 위해서
